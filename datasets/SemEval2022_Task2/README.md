# SemEval 2022 Task 2: Idiomaticity

This dataset corresponds to SemEval 2022 Task 2, which focuses on idiomaticity detection and semantic similarity.

## Task Details

### Task A: Idiom Detection
Task A involves detecting whether a specific expression in a sentence is used idiomatically or literally. The goal is to classify the usage of potential idioms.

### Task B: Semantic Similarity
Task B involves establishing the semantic similarity between two sentences. Specifically, one sentence contains an idiom, and the other sentence has the idiom replaced with a different wording (paraphrase or literal meaning). The task is to determine how similar the meanings of the two sentences are.
